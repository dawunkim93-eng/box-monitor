박스 안에서 진동하는 국내 주식을 실시간으로 관찰하고, 연금 3계좌를 함께 관리하는 대시보드.

## 운영 원칙 (2026-11-13 정리)

현재 시스템에 실제로 들어가 있는 값이다. 13년 검증(2014~2026)에서 살아남은 규칙만 남겼다.

### 1. 무엇을 사는가
- 주봉 6주 종가 밴드 성립: 폭 20~30%, 순드리프트 ±15% 이내, 20일 평균 거래대금 10억원 이상
- 밴드 위치 하위 50% 이내
- 보유 중이 아닌 종목

### 2. 언제 사는가
- 신호 판정은 **전일 종가** 기준. 종가 ≥ 밴드 하단 × 1.02 × 1.06 (여지 6%, 하단 대비 약 +8%)
- 전일이 음봉
- 주문은 **전일 종가 지정가**. 시가가 낮으면 시가 체결, 높으면 미체결로 스킵(추격 금지)
- 장중에 ✅가 떠도 현재가가 지정가 위면 사지 않는다 (2026-11-06~13 복기: 손실 6건 전부 이 경우)

### 3. 얼마나
- 슬롯 7개(무료 앱), 슬롯당 51만원: 1차 6만, 2차 6만, 3차 9만, 4차 12만, 5차 18만
- 밴드 하단이 250일 거래대금 가중평균가(VWAP) **위**면 그 슬롯은 102만원: 12·12·18·24·36만
- 후보가 슬롯보다 많으면 점수 높은 순

### 4. 언제 파는가
- **종가**가 밴드 하단 × 1.02 아래면 청산. 장중에 잠깐 찍히는 것은 청산 사유가 아니다
- 보유분 청산선은 **진입 시점 밴드로 고정**. 밴드가 재계산돼도 따라 올리지 않는다
- 각 차수는 +2% 도달 시 매도. 전량 매도되면 슬롯 종료(재그리드 없음)
- 코스피 -3% 이하 마감 다음 날은 신규 진입 중단

### 5. 하지 말 것
- 여지 6% 미달 상태에서 사는 것 (2026-11 복기: 손실 6건 전부 미달 진입)
- 장중 이탈로 파는 것 (에스엠 사례: 조기 매도 -4.5%, 이틀 뒤 회복)
- 장중 급등 후 추격 매수
- 검증에서 진 대안: 상승저점 박스(A박스), 눌림 단독, 눌림+박스, 반전 돌파, 1년 혼잡구간 박스, 13주 밴드

### 6. 하루 흐름
| 시각 | 할 일 |
|---|---|
| 08:15 | 아침 알림 확인, 후보와 지정가 확인 |
| 09:02~15:47 | 지정가 도달 알림 시 주문 (사이트는 15분 갱신) |
| 15:20~15:30 | 종가 단일가, 이 종가로 청산 판정 |
| 16:10 | 마감 확정 알림, 청산 여부 확인 |
| 16:40 | 복기 스냅샷, 규칙 위반 확인 |
| 16:45 | 지지선 박스 관찰 목록 갱신 |

|---|---|
| 포지션 | 5,171건 |
| 순익 | 1,317만원 |

### 8. 바꾸지 말아야 할 것
- **주봉 6주**: 4주는 건당 수익 하락, 13주는 낙폭 확대, 26주는 순익 1/3
- **폭 하한 20%**: 그 미만은 청산선이 가까워 잦은 손절
- **여지 하한 6%**: 4%면 4·5차가 청산선 아래로 들어가 사다리 절반이 죽는다. 6%에서 낙폭 -34%, 순익/낙폭 117 → 181
- **종가 청산**: 장중 청산보다 순익 43% 높고 낙폭은 1.5배 수준
- **매물대 위 ×2**: 순익 +29%, 낙폭 +12%, 위험 대비 개선

## 연금 탭 (2026-11 추가)

상단 대분류가 `데일리매매`와 `연금`으로 나뉩니다. `연금` 안의 하위 탭에서 세 계좌(연금저축, IRP, ISA) 전략과 보유분 정리, 리밸런싱 제안을 볼 수 있습니다.

- **전략**: 계좌별 배분, 납입 순서(세액공제 900만원 → ISA → 비과세 연금), ISA 3년 순환 숫자, 2027년 청년 IRP 분기, 리스크 규칙(테마 30% 상한), 확인 일정(D-day, 지나면 빨간색)
- **보유분**: 종목명 자동완성(ETF 1,184종목), 수량과 평균단가 입력, 현재가 자동 반영(장 마감 후 하루 1회 배포), 평가액과 수익률 표시. 각 항목의 ✎로 계좌, 구분, 수량, 평단을 고칠 수 있습니다(리밸런싱 실행 후 수량 갱신용). 브라우저 localStorage에만 저장되며 서버로 전송하지 않습니다.
- **밸런싱**: 목표 비중과 현재 비중을 막대로 비교하고, 차이를 매수와 매도 금액으로 계산합니다. 구분별 수익률과 조정 필요 여부(5%포인트 기준)를 함께 보여줍니다. IRP 위험자산 70%, 테마 합산 30%, 단일 테마 10%를 자동 점검합니다.

가격은 `scripts/pen_prices.py`가 네이버 ETF 목록을 받아 `data/pen_prices.json`으로 저장합니다. 크론이 평일 16:25에 한 번 갱신하고 커밋합니다.

> 입력값은 기기별 브라우저에 저장되므로 다른 기기와 공유되지 않습니다. 투자 권유나 세무 자문이 아닙니다.

## 복기 탭 (데일리매매)

장 마감 뒤 그날의 신호와 실제 체결을 대조합니다.

- 왼쪽(자동): `scripts/box_review.py`가 16:40에 오늘의 진입 후보, 시스템 진입 기록, 청산 신호, 경고를 모아 `data/box_review.json`으로 저장합니다.
- 오른쪽(입력): 실제 체결을 종목, 구분, 가격, 수량으로 넣습니다. 브라우저에 날짜별로 저장됩니다.
- 대조 규칙: 쿨다운 날 매수, 신호에 없던 매수, 신호가 대비 3% 초과 추격, 7슬롯 초과, 청산한 종목 당일 재매수.
- "에이전트에게 복기 요청" 버튼은 오늘 신호와 체결을 담은 질문을 복사합니다.

## 대상 종목 조건 (주봉 6주 종가 밴드)

| # | 조건 | 기준 |
|---|---|---|
| 1 | 박스 정의 | 6주 주봉 **종가** 밴드 (최저~최고) |
| 2 | 박스 폭 | 최고/최저 − 1 ≤ 30% |
| 3 | 횡보 | 6주 순드리프트(마지막/처음 − 1) ≤ ±15% |
| 4 | 매수존 | 현재가가 밴드 **하위 절반**(위치 ≤ 50%) |
| 5 | 유동성 | 20일 평균 거래대금 ≥ 10억원 |
| 6 | 무결성 | 일간 등락 ±60% 초과 이력 종목 제외 (분할·병합 비조정) |

> 청산·스톱이 동시에 꺼지는 테일이 있었고(10만원 초과 손실 13건 전부 A박스), 검증에서도
> A박스 제외가 순익·MDD 모두 우위였습니다. 재편입은 `box_alert.POOL_ABOX = True` + 재검증 후.

## 진입 / 청산 / 사다리

- **진입**: 매수존(밴드 하위 절반, **경계 +6% 이상 = 여지 4%**) + 전일 음봉 → 다음날 시가
- **사다리**: 갭 **2.0%** · **5차**(최심 −7.8%) · 금액 **6·6·9·12·18만(1:1:1.5:2:3)** → 슬롯 51만원
  - 차수별 **+2.0%** 지정가 매도 (당일 재왕복 가정은 검증에만 존재)
- **청산**: ① **종가**가 밴드 하단×1.02 아래 → 슬롯 전량 청산 (진입일 포함, 장중 흔들림은 무시) ② 밴드 소멸(폭·드리프트 이탈, 상단 돌파)
- **백스톱** −15%는 형식적입니다 — 13년 발동 0건. 실제 리스크 통제는 ①입니다.

> 2% 갭 5차 = 하단 약 10% 커버. 차수를 늘리면 커버가 박스 폭(≤30%) 밖으로 나갑니다
> (15차 = −26%). 2.5% 갭 실측에서 15차는 5차 대비 순익 +6%·MDD +77%였습니다.

  실적 추정에는 `all`을 쓰는 것이 맞습니다. 사이트 검증 탭도 두 수치를 함께 표시합니다.

## 갱신

- 데이터는 장중 **15분 간격**으로 홈서버가 현재가를 조회해 `data/box_live.json`을 갱신·push
- 장마감 후/휴일은 마지막 종가 유지, 실질 변경 없으면 커밋 스킵
- 최종 확정 판정(종가 기준)은 알림 채널(텔레그램)이 담당 — 본 사이트는 참고용 실시간 뷰
- **급락 쿨다운**: 전일 KOSPI −3% 이하 마감 시 08:15 알림과 사이트 상단에 "오늘 신규 진입 스킵" 배너가 뜹니다(1거래일).

## 기술

단일 정적 페이지(vanilla JS) + JSON. 빌드·의존성 없음.
데이터 생성은 별도 백테스트 리포(`magicsplit-safe-strategy`의 `box_alert.py` 계열)가 담당하며,
이 리포는 표시 계층 + 검증 스크립트(`scripts/box_validation.py`)를 담당합니다.

## 지지선 박스 관찰 (2026-11-10 추가)

주봉 박스(6주 밴드)가 놓치는 완만한 종목을 찾기 위한 관찰 목록이다. 매매 신호가 아니다.

| 항목 | 규칙 |
|---|---|
| 창 | 주봉 52주(1년) |
| 지지선 | 최근 4주를 뺀 48주 안에서 가장 낮은 종가 |
| 저항선 | 52주 최고가 |
| 박스 폭 | 20~60% |
| 지지 확인 | 지지선 ±3% 터치 후 종가가 위로 마감한 주가 3회 이상, 최근 13주에 1회 이상 |
| 상단 미돌파 | 52주 안에 종가가 저항선 위로 간 적 없음 |
| 지지선 안정 | 13주 전 지지선보다 3% 넘게 낮아지지 않음 |
| 진입 위치 | 현재가가 지지선 위 0~8% |

산출물은 `data/box_lbox.json`, 스크립트는 `scripts/lbox_scan.py`, 크론은 평일 16:45다.
사이트 실시간 탭 하단 "지지선 박스 관찰"에서 상단 여지, 폭, 위치, 지지 횟수를 본다.
