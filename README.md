|---|---|---|

| 2 | 박스 폭 | 최고/최저 − 1 ≤ 30% |
| 3 | 횡보 | 13주 순드리프트(마지막/처음 − 1) ≤ ±15% |
| 4 | 매수존 | 현재가가 밴드 **하위 절반**(위치 ≤ 50%) |
| 5 | 유동성 | 20일 평균 거래대금 ≥ 10억원 |
| 6 | 무결성 | 일간 등락 ±60% 초과 이력 종목 제외 (분할·병합 비조정) |
| 7 | 제외 | 관리종목·투자주의환기(KRX) + 자본총계 ≤ 0 (DART PIT) |

> 2026-11-06부터 **상승저점(A박스)은 풀에서 제외**했습니다. 경계(추세선)가 급락일 NaN이 되어
> 청산·스톱이 동시에 꺼지는 테일이 있었고(10만원 초과 손실 13건 전부 A박스), 검증에서도
> A박스 제외가 순익·MDD 모두 우위였습니다. 재편입은 `box_alert.POOL_ABOX = True` + 재검증 후.

## 진입 / 청산 / 사다리

- **진입**: 매수존(밴드 하위 절반, **경계 +6% 이상 = 여지 4%**) + 전일 음봉·아래꼬리 1%+ → 다음날 시가
- **사다리**: 갭 2.5% · **5차**(최심 −9.6%) · 10만원/차 → 슬롯당 50만원
  - 차수별 +2.5% 지정가 매도 (당일 재왕복 가정은 검증에만 존재)
- **청산**: ① 장중 가격이 밴드 하단×1.02를 터치 → 슬롯 전량 **즉시** (진입일 포함, 종가 대기 금지) ② 밴드 소멸(폭·드리프트 이탈, 상단 돌파)
- **백스톱** −15%는 형식적입니다 — 13년 7,235 포지션에서 발동 0건. 실제 리스크 통제는 ①입니다.

> 15차(−30% 커버)는 박스 폭(≤30%) 밖입니다. 5차 대비 순익 +6% · MDD +77%로 리스크만 늘어
> 5차로 축소했습니다 (2026-11-06 실측).

+ ATR 3~7% +1 + 밴드 폭 ≥26% +2 · 22~26% +1

|---|---|---|

| 3~4 | 63.1% | +2,161원 |
| 5~6 | 65.0% | +2,500원 |

탈출율 배지는 검증 JSON의 `score_escape` 실측값을 그대로 읽습니다(하드코딩 아님).
7슬롯(무료 앱) 환경에서는 슬롯이 자주 차므로 점수 순위가 실제로 작동합니다 —
S2c·7슬롯에서 점수 역순은 all +3,425,408원으로 정순(+4,296,074원)보다 20% 낮았습니다.
단, 점수로 **걸러내면** 수익이 줄어듭니다(7점 중 6점 이상만: all +3,304,748원, 전부 +4,296,074원).

## 검증 (2014-09 ~ 2026-11, 13년, 4,591 포지션 · 7슬롯 · 무료 앱 기준)

| 당일 매도 가정 | 총손익 | MDD |
|---|---|---|
| multi (같은 차수 당일 재왕복 포함) | +11,849,274원 | −94,218원 |
| all (지정가 터치 시 체결) | +4,296,074원 | −186,863원 |
| close (종가 ≥ 목표가일 때만) | −2,031,824원 | −2,362,441원 |
| none (당일 신규차수 매도 금지) | −2,220,034원 | −2,509,042원 |

- 1차 탈출 65.3% · 평균 보유 2.2일 · 연 353포지션 · 필요자본 peak 180만원
- **무료 버전 모델입니다**: 전 차수 매도(1차 탈출) 시 슬롯을 닫고, 같은 종목 재그리드 없음.
  유료 '수익 극대화'(슬롯 유지+재그리드)로 돌리면 all +4,534,057원·MDD −125,674원이지만
  **구독 전에는 재현할 수 없으므로** 검증 기준을 무료 모델로 바꿨습니다.
- **슬롯 계산은 보수적입니다**: 보유 종목이 슬롯을 차지하고, 진입은 그날 시가에 빈 슬롯이 있을 때만
  점수 순으로 채웁니다. 같은 날 청산으로 생긴 슬롯은 **다음 거래일부터** 반영합니다.
- **multi는 순익의 약 60%를 같은 차수 당일 재왕복에서 만듭니다.** 실계좌 재현이 어려우므로
  실적 추정에는 `all`을 쓰는 것이 맞습니다. 사이트 검증 탭도 두 수치를 함께 표시합니다.
- 청산 경로: 1차탈출 회전 3,000 · 하단근접(장중) 1,302 · 하단근접(당일) 195 · 박스 소멸 89 (all 모드)
- **여지(room) 필터**: 진입가에서 경계×1.02까지 4% 미만이면 진입하지 않습니다.
  무료 모델 기준 room0 대비 순익 +9%·MDD −25%·탈출 +7%p 개선(2026-11-06 실측).

## 화면 구성

- **⚠️ 장중 이탈 경고**: 현재가 < 전일 박스 하단 (⛔ = −5% 초과 심화)
- **전체 목록**: ATR 내림차순 기본, 정렬 토글 · 위치 색상바(하단 파랑/상단 초록/이탈 빨강)
- **🟢 재무강화 태그**: 부채<200%·ROE>0·4중3 — 정보 표시 (점수 미반영)
- ⭐ 즐겨찾기: 보유 종목 고정 (브라우저 로컬 저장 — 서버 전송 없음)

## 갱신

- 데이터는 장중 **15분 간격**으로 홈서버가 현재가를 조회해 `data/box_live.json`을 갱신·push
- 장마감 후/휴일은 마지막 종가 유지, 실질 변경 없으면 커밋 스킵
- 최종 확정 판정(종가 기준)은 알림 채널(텔레그램)이 담당 — 본 사이트는 참고용 실시간 뷰
- **급락 쿨다운**: 전일 KOSPI −3% 이하 마감 시 08:15 알림과 사이트 상단에 "오늘 신규 진입 스킵" 배너가 뜹니다(1거래일).

## 기술

단일 정적 페이지(vanilla JS) + JSON. 빌드·의존성 없음.
데이터 생성은 별도 백테스트 리포(`magicsplit-safe-strategy`의 `box_alert.py` 계열)가 담당하며,
이 리포는 표시 계층 + 검증 스크립트(`scripts/box_validation.py`)를 담당합니다.
