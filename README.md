> 청산·스톱이 동시에 꺼지는 테일이 있었고(10만원 초과 손실 13건 전부 A박스), 검증에서도
> A박스 제외가 순익·MDD 모두 우위였습니다. 재편입은 `box_alert.POOL_ABOX = True` + 재검증 후.

## 진입 / 청산 / 사다리

- **진입**: 매수존(밴드 하위 절반, 경계 +2% 이상) + 전일 음봉·아래꼬리 1%+ → 다음날 시가
- **사다리**: 갭 2.5% · **5차**(최심 −9.6%) · 10만원/차 → 슬롯당 50만원
  - 차수별 +2.5% 지정가 매도 (당일 재왕복 가정은 검증에만 존재)
- **청산**: ① 장중 가격이 밴드 하단×1.02를 터치 → 슬롯 전량 **즉시** (진입일 포함, 종가 대기 금지) ② 밴드 소멸(폭·드리프트 이탈, 상단 돌파)
- **백스톱** −15%는 형식적입니다 — 13년 7,235 포지션에서 발동 0건. 실제 리스크 통제는 ①입니다.

> 15차(−30% 커버)는 박스 폭(≤30%) 밖입니다. 5차 대비 순익 +6% · MDD +77%로 리스크만 늘어
> 5차로 축소했습니다 (2026-11-06 실측).

## 화면 구성

- **⚠️ 장중 이탈 경고**: 현재가 < 전일 박스 하단 (⛔ = −5% 초과 심화)
- **전체 목록**: ATR 내림차순 기본, 정렬 토글 · 위치 색상바(하단 파랑/상단 초록/이탈 빨강)
- **🟢 재무강화 태그**: 부채<200%·ROE>0·4중3 — 정보 표시 (점수 미반영)
- ⭐ 즐겨찾기: 보유 종목 고정 (브라우저 로컬 저장 — 서버 전송 없음)

## 갱신

- 데이터는 장중 **15분 간격**으로 홈서버가 현재가를 조회해 `data/box_live.json`을 갱신·push
- 장마감 후/휴일은 마지막 종가 유지, 실질 변경 없으면 커밋 스킵
- 최종 확정 판정(종가 기준)은 알림 채널(텔레그램)이 담당 — 본 사이트는 참고용 실시간 뷰

## 기술

단일 정적 페이지(vanilla JS) + JSON. 빌드·의존성 없음.
데이터 생성은 별도 백테스트 리포(`magicsplit-safe-strategy`의 `box_alert.py` 계열)가 담당하며,
이 리포는 표시 계층 + 검증 스크립트(`scripts/box_validation.py`)를 담당합니다.
