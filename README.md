# 📦 박스권 모니터

박스 안에서 진동하는 고변동 국내 주식을 실시간으로 관찰하는 대시보드.
**사다리 그리드 수확(하락 차수 매수 → +갭 매도 반복) 관찰용 · 관찰 전용이며 진입 권장 아님.**

⟶ 열기: <https://dawunkim93-eng.github.io/box-monitor/>

## 대상 종목 조건 (10년 파일럿 검증 기반)

| # | 조건 | 기준 |
|---|---|---|
| 1 | 박스 높이 | 60거래일 고가/저가 = 1.25~2.2배 |
| 2 | 횡보 | 60일 전 종가 대비 \|변동\| ≤ 20% |
| 3 | 고변동 | ATR(14)/종가 ≥ 3.0% (Wilder) |
| 4 | 박스 안정 | ①~③ **20거래일 연속** 만족 |
| 5 | 유동성 | 20일 평균 거래대금 ≥ 10억원 |
| 6 | 무결성 | 일간 등락 ±60% 초과 이력 종목 제외 |

## 매수 우선순위 점수 (백테스트 검증)

점수 = 박스나이(≥31일 +3 · ≥61일 +4) + 현재위치(35~50% +2 · 25~35% +1 · **하단 25% 미만은 0**) +
ATR(≥5% +2 · ≥4% +1) + 상승기울기 +1 + 박스높이 ≤1.8배 +1

| 점수 | 1차 탈출율 | 건당 수익 | 1차 손실률 |
|---|---|---|---|
| 0~2 | 45.3% | +1,839원 | 54.7% |
| 3~4 | 64.0% | +3,774원 | 36.0% |
| 5~6 | 76.3% | +8,006원 | 23.7% |
| **7~11 (🥇)** | **99.4%** | **+41,986원** | **0.6%** |

- 10년 33,569 에피소드 실측 · 탈출율 = 진입 후 +갭 도달(1차 러그매도) 성공률
- **갭 = 2.5% 고정** (2026-10-26) — 10년 5설정 비교(1.5%+473만 / 2%+1,147만 / **2.5%+1,273만** / 3%+1,167만 / ATR티어+998만)에서 최적
- **반직관 발견**: 박스 하단(0~10%) 진입이 최악(붕괴 임박) — 중간(35~50%)에서 시작해 진동 수확이 최적
- 현행 ATR순 랭킹(건당 +9,912원) 대비 점수순은 +18,146원으로 1.8배

## 화면 구성

- **⚠️ 장중 이탈 경고**: 현재가 < 전일 박스 하단 (⛔ = -5% 초과 심화)
- **전체 목록**: ATR 내림차순 기본, 정렬 토글 · 위치 색상바(하단 파랑/상단 초록/이탈 빨강)
- **🟢 재무강화 태그**: 부채<200%·ROE>0·4중3 — 정보 표시 (수익 예측력은 ATR이 우위, 10년 실측)
- ⭐ 즐겨찾기: 보유 종목 고정 (브라우저 로컬 저장 — 서버 전송 없음)

## 갱신

- 데이터는 장중 **15분 간격**으로 홈서버가 현재가를 조회해 `data/box_live.json`을 갱신·push
- 장마감 후/휴일은 마지막 종가 유지, 실질 변경 없으면 커밋 스킵
- 최종 확정 판정(종가 기준)은 알림 채널(텔레그램)이 담당 — 본 사이트는 참고용 실시간 뷰

## 기술

단일 정적 페이지(vanilla JS) + JSON. 빌드·의존성 없음.
데이터 생성은 별도 백테스트 리포(magicsplit-safe-strategy의 `box_alert.py` 계열)가 담당하며,
이 리포는 표시 계층만 담당합니다.
